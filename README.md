# นาข้าว AI — คู่มือติดตั้งแบบไม่ต้องเขียนโค้ด

โฟลเดอร์นี้พร้อมสำหรับเอาขึ้นเว็บผ่าน **Vercel** (ฟรี) ซึ่งจะทำให้:
- คีย์ AI กลางของทีมถูกซ่อนไว้ ไม่มีใครเห็นจากหน้าเว็บ
- ได้ลิงก์ https:// ใช้กดปุ่ม "เพิ่มไปที่หน้าจอโฮม" บนมือถือ ได้ไอคอนเหมือนแอพจริง

## ขั้นตอน (ทำครั้งเดียว)

1. **สร้างบัญชี GitHub** (ถ้ายังไม่มี) ที่ github.com แล้วสร้าง repository ใหม่ (ตั้งชื่ออะไรก็ได้ เช่น `rice-app`)
2. **อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้** ขึ้น repository นั้น (ลากไฟล์วางบนหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้คำสั่ง)
3. **สร้างบัญชี Vercel** ที่ vercel.com โดยกด "Sign up with GitHub" (ใช้บัญชี GitHub เดียวกัน)
4. ใน Vercel กด **"Add New" → "Project"** แล้วเลือก repository `rice-app` ที่เพิ่งสร้าง
5. ก่อนกด Deploy ให้เปิดส่วน **Environment Variables** แล้วเพิ่ม:
   - Name: `ANTHROPIC_API_KEY`
   - Value: (คีย์ API ของทีม จาก console.anthropic.com)
6. กด **Deploy** รอสักครู่ Vercel จะให้ลิงก์เว็บมา เช่น `rice-app-xxxx.vercel.app`
7. เปิดลิงก์นั้นบนมือถือ (Chrome/Safari) → กดเมนู → **"เพิ่มไปที่หน้าจอโฮม"** จะได้ไอคอน 🌾 กดเปิดเหมือนแอพจริง

## การใช้งานหลังติดตั้ง

- สมาชิกทีมทุกคนเปิดลิงก์เดียวกัน ใช้งานได้เลย **ไม่ต้องกรอกคีย์อะไรทั้งสิ้น** (ใช้คีย์กลางที่ซ่อนอยู่ใน Vercel)
- ถ้าอยากทดสอบด้วยคีย์ส่วนตัวแทน กดปุ่มรูปเฟือง ⚙️ มุมขวาบนของแอพ แล้วกรอกคีย์ของตัวเองได้ — จะมีผลแค่เครื่องนั้นเครื่องเดียว

## อัปเดตแอพภายหลัง

แก้ไขไฟล์แล้วอัปโหลดขึ้น GitHub repository เดิม Vercel จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — หน้าตาแอพทั้งหมด
- `api/analyze.js` — ฟังก์ชันฝั่งเซิร์ฟเวอร์ที่ถือคีย์กลางไว้ (ไม่ถูกส่งให้ผู้ใช้เห็น)
- `manifest.json`, `icons/` — สำหรับให้ติดตั้งเป็นไอคอนบนมือถือได้
- `sw.js` — ทำให้เปิดแอพได้ลื่นขึ้นและรองรับการติดตั้ง

## ตอนเปิดสาธารณะในอนาคต

เมื่อพร้อมเปิดให้คนนอกใช้ ควรกลับมาคุยกันเรื่อง:
- จำกัดจำนวนครั้งต่อคน/ต่อวัน (กัน key โดนใช้เกินจนมีค่าใช้จ่ายสูง)
- อาจต้องมีระบบล็อกอินง่ายๆ เพื่อนับการใช้งานแยกรายคน
